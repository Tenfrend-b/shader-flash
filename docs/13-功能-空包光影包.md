# 功能：「空包」光影包（0.1.11）

## 它解决什么

双管线的两边都必须是“光影管线”。于是当你想让其中一边是**原生渲染**时就没得选了：
把 Iris 的光影关掉只会得到 `VanillaRenderingPipeline`，它不参与双管线
（副管线无法构建、F7 也没有对照物）。

「空包」把这件事补上：让 Iris **以外置光影包的形式**加载“原版的着色器”，
于是“原生渲染”就成了一条普通的光影管线，可以：

* 在 **Iris 的选包界面**里选中它 → 当前主管线就是原生渲染；
* 在**本模组的副管线列表**里选中它 → 副管线就是原生渲染；
* 于是 F7 秒切、副管线截图、兼容性自检、材质表/网格重做、维度变化重建……全部照旧工作。

# 功能：「空包」光影包（0.1.11 新增，0.1.12 改为真·原生管线）

> **0.1.12 起，「空包」绑定的是 Iris 自己的原生管线**（`VanillaRenderingPipeline`，
> 也就是“把光影关掉”时用的那条），所以画面是**逐像素的原生渲染**，不再是 fallback 近似。
> 实现见 `IrisPipelineFactoryMixin`：当当前包名是「空包」时，`Iris.createPipeline(...)`
> 返回 `new VanillaRenderingPipeline()`。下面「空包 → Iris fallback」那段仍然成立
> （包本身确实不含任何程序），但它只解释“这个包为什么能被 Iris 正常加载与列出”，
> 不再决定画面。另外：主管线是原生管线时，模组现在**照常渲染副管线那一遍**，
> 所以「空包 ↔ 光影包」的 F7 秒切依旧成立。

## 它是什么（实现）

模组在 `shaderpacks/` 下生成一个真实的目录型光影包：

```
shaderpacks/空包/
└── shaders/
    └── shaders.properties     ← 只有说明性注释，没有任何程序
```

**为什么“空包”≈ 原生等效着色器**：Iris 对**缺省的程序**会走它自己的 fallback 路径 ——
按原生渲染的语义合成一份等价程序（`ShaderCreator.createFallback` / `ShaderSynthesizer`）；
Sodium 的地形程序则退回 Sodium 自带的原生等价程序
（`IrisChunkProgramOverrides.createShader` 在包没提供地形着色器时返回 `null`，
`createShaders` 会把该 pass 记成 `null`，Sodium 就用它自己的）。
也就是说「空包」在 Iris 里本来就被当作“尽量按原生渲染”。

**为什么做成文件包**：

* Iris 的选包界面直接枚举 `shaderpacks/`：
  `ShaderpackDirectoryManager.enumerate()` 用 `Iris.isValidToShowPack(path)`
  过滤（`Files.isDirectory(pack) || pack.endsWith(".zip")`），所以一个目录就是一个包 ——
  **不需要改 Iris 的界面代码**，条目自动出现在 Iris 的列表里；
* Iris 加载目录包的路径是 `Iris.tryLoadShaderpack` → `<包>/shaders`，
  选项文件是 `<包名>.txt`，都和普通包一致；
* 因此本模组不需要为「空包」写任何特判，功能天然兼容。

**生成策略**：只补缺失文件。包目录已经存在（哪怕是玩家自己放的同名包）就一个字都不动；
玩家往里面塞自己的程序后，列表里的「（原生等效着色器）」标注会自动收起
（`VanillaPack.isPristine()` 检查有没有 `.vsh/.fsh/.gsh/.csh/.tcs/.tes`）。

## 怎么用

1. 启动一次游戏（模组会把包生成出来）。也可以在设置界面里用
   「**「空包」光影包条目**」开关控制是否生成 —— 关掉不会删除已经生成的包。
2. **当主管线**：Iris 的选包界面（默认快捷键可在“选项 → 控制”里查）→ 选中 `原版`。
3. **当副管线**：本模组设置界面（F8）左侧列表 → 选中 `◆ 空包（空包：原生等效，非原版）`。
   选中后会在后台预编译，随后 F7 即可在“原版 ↔ 光影包”之间秒切。

## 已知差异

* 「空包」走的是 Iris 的 fallback，而**不是**“把光影关掉”的那条原生管线（`VanillaRenderingPipeline`）。
  观感非常接近，但不保证逐像素相同（Iris 自己的注释里就提到：fallback 的 Sodium 地形
  “不支持水下的 EXP2 雾”）。要**完全**原生请在 Iris 里关掉光影 ——
  代价是那条管线不参与双管线。
* 与任何光影包一样，从「空包」切走/切回会触发一次材质表差异判定；
  材质表不同时会走一次后台网格重建（`原版` 没有 `block.properties`，
  所有方块都是“未知材质”，这正是原生渲染的语义）。
* 「空包」包不提供任何程序，所以「兼容性自检」里那一行会全是「=无」；
  模组会额外打一行提示说明这是预期行为。
